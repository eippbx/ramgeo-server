## 1. 项目概述

### 1.1 项目背景

节点服务器（Node Server）是Ramgeo分布式计算系统的核心组件之一，负责接收代理服务器分配的计算任务，执行ramgeo计算程序，并将结果返回给代理服务器。节点服务器需要具备高可靠性、高可用性和良好的容错能力。

### 1.2 项目目标

- 实现与代理服务器的WebSocket通信
- 支持任务接收、执行和结果上传
- 提供资源监控和状态报告功能
- 实现自动重连和错误恢复机制
- 支持大文件的分片传输

### 1.3 系统架构

节点服务器采用模块化设计，主要包含以下核心组件：

```
node_server/
├── main.py              # 主程序入口
├── config/
│   └── node_config.yaml # 配置文件
├── src/
│   ├── config.py        # 配置管理模块
│   ├── node_server.py   # 节点服务器核心模块
│   ├── websocket_client.py # WebSocket客户端模块
│   ├── task.py          # 任务处理模块
│   ├── file_manager.py  # 文件管理模块
│   └── resource_monitor.py # 资源监控模块
├── bin/
│   └── ramgeo          # ramgeo可执行文件
├── work/               # 工作目录
└── logs/               # 日志目录
```

#### 3.3.2 文件分片传输

实现大文件的分片传输和完整性验证：

```python
async def upload_file(self, file_path: str, file_name: str, chunk_size: int = 1024 * 1024 * 5):
    # 计算文件哈希
    file_hash = hashlib.md5()
    with open(file_path, 'rb') as f:
        for chunk in iter(lambda: f.read(8192), b''):
            file_hash.update(chunk)
    
    # 读取文件并分片
    chunks = []
    with open(file_path, 'rb') as f:
        while True:
            chunk_data = f.read(chunk_size)
            if not chunk_data:
                break
            chunks.append(chunk_data)
    
    # 逐个发送分片
    for index, chunk_data in enumerate(chunks):
        chunk_md5 = hashlib.md5(chunk_data).hexdigest()
        chunk_base64 = base64.b64encode(chunk_data).decode('utf-8')
        
        message = {
            'type': 'file_transfer',
            'transfer_id': file_name,
            'chunk': chunk_base64,
            'index': index,
            'total_chunks': total_chunks,
            'file_hash': file_md5,
            'chunk_hash': chunk_md5
        }
        
        await self.send_message(message)
```

#### 3.3.3 指数退避重连

实现指数退避策略的自动重连：

```python
async def run(self):
    backoff_time = self.reconnect_interval
    max_backoff_time = 60
    
    while True:
        if not self.is_connected:
            try:
                connected = await self.connect()
                if connected:
                    backoff_time = self.reconnect_interval
            except Exception as e:
                self.reconnect_attempts += 1
                if self.reconnect_attempts >= self.max_reconnect_attempts:
                    break
                
                logger.warning(f"连接失败 ({self.reconnect_attempts}/{self.max_reconnect_attempts})，{backoff_time}秒后重试...")
                await asyncio.sleep(backoff_time)
                
                backoff_time = min(backoff_time * 2, max_backoff_time)
```
