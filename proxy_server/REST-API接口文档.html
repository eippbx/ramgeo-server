REST API 接口文档

1. 概述

本文档详细描述了 RAMGEO 代理服务器的 REST API 接口规范。所有接口均采用 RESTful 架构设计，使用 JSON 格式进行数据交换。

1.1 基础信息

  • 基础URL: http://<host>:<port>/api/v1
  • 协议: HTTP/1.1
  • 数据格式: JSON
  • 字符编码: UTF-8

1.2 通用响应格式

所有接口返回的响应都遵循以下格式：

成功响应

  1. {
  2.   "data": {},
  3.   "message": "Success",
  4.   "timestamp": "2023-01-01T12:00:00Z"
  5. }

错误响应

  1. {
  2.   "detail": "Error message",
  3.   "timestamp": "2023-01-01T12:00:00Z"
  4. }

1.3 HTTP 状态码

状态码 描述 使用场景
200 OK 请求成功
400 Bad Request 请求参数错误
404 Not Found 资源不存在
500 Internal Server Error 服务器内部错误

1.4 认证

当前版本不需要认证，所有接口均可直接访问。

2. 系统状态接口

2.1 获取系统状态

获取代理服务器的运行状态。

Endpoint: GET /api/v1/status

请求参数: 无

响应示例:

  1. {
  2.   "status": "ok",
  3.   "timestamp": "2023-01-01T12:00:00Z"
  4. }

字段说明:

字段名 类型 描述
status string 系统状态，”ok” 表示正常
timestamp string 响应时间戳（ISO 8601格式）

字段说明:

字段名 类型 描述

ip_address string 节点 IP 地址

4. 任务管理接口

4.1 上传任务文件

上传任务文件并创建新任务。

Endpoint: POST /api/v1/tasks/upload

请求参数:

参数名 类型 必选 描述
task_type string 是 任务类型（查询参数）
file file 是 任务输入文件（表单数据）
chunk_index integer 否 分片索引（分片上传时使用）
total_chunks integer 否 总分片数（分片上传时使用）
file_hash string 否 文件 MD5 哈希值（可选）

请求示例:

  1. curl -X POST "http://localhost:8080/api/v1/tasks/upload?task_type=ramgeo" \
  2.   -F "file=@input_file.in"

响应示例:

  1. {
  2.   "task_id": "task-1767414007-8eaebe5e",
  3.   "status": "pending"
  4. }

字段说明:

字段名 类型 描述
task_id string 任务唯一标识符
status string 任务状态

分片上传响应示例:

  1. {
  2.   "task_id": "task-1767414007-8eaebe5e",
  3.   "chunk_index": 0,
  4.   "status": "chunk_received"
  5. }

错误响应:

  1. {
  2.   "detail": "Failed to upload task file: error message"
  3. }

4.2 获取任务列表

获取任务列表，支持按状态和优先级过滤。

Endpoint: GET /api/v1/tasks

查询参数:

参数名 类型 必选 描述
status string 否 按任务状态过滤（PENDING/RUNNING/COMPLETED/FAILED/CANCELLED）
priority string 否 按任务优先级过滤（LOW/NORMAL/HIGH/URGENT）
limit integer 否 最大返回数量（默认100，范围1-1000）
offset integer 否 分页偏移量（默认0）

请求示例:

  1. curl -X GET "http://localhost:8080/api/v1/tasks?status=COMPLETED&limit=10&offset=0"

响应示例:

  1. {
  2.   "tasks": [
  3.     {
  4.       "task_id": "task-1767414007-8eaebe5e",
  5.       "status": "COMPLETED",
  6.       "assigned_node_id": "node-001",
  7.       "created_at": "2023-01-01T12:00:00Z",
  8.       "started_at": "2023-01-01T12:00:01Z",
  9.       "completed_at": "2023-01-01T12:00:30Z",
  10.       "error": null,
  11.       "retry_count": 0,
  12.       "file_uploaded": true
  13.     }
  14.   ],
  15.   "total": 1,
  16.   "limit": 10,
  17.   "offset": 0
  18. }

字段说明:

字段名 类型 描述
tasks array 任务信息数组
total integer 符合条件的任务总数
limit integer 返回的最大任务数
offset integer 分页偏移量

任务信息字段说明:

字段名 类型 描述
task_id string 任务唯一标识符
status string 任务状态（PENDING/RUNNING/COMPLETED/FAILED/CANCELLED）
assigned_node_id string 分配的节点 ID（未分配时为 null）
created_at string 任务创建时间（ISO 8601格式）
started_at string 任务开始时间（ISO 8601格式，未开始时为 null）
completed_at string 任务完成时间（ISO 8601格式，未完成时为 null）
error string 错误信息（无错误时为 null）
retry_count integer 重试次数
file_uploaded boolean 文件是否已上传

6. 错误处理

6.1 通用错误响应

所有错误响应都遵循以下格式：

  1. {
  2.   "detail": "Error message",
  3.   "timestamp": "2023-01-01T12:00:00Z"
  4. }

6.2 常见错误码

HTTP 状态码 错误描述 处理建议
400 Bad Request 检查请求参数是否正确
404 Not Found 检查资源 ID 是否正确
500 Internal Server Error 联系系统管理员

6.3 业务错误

错误信息 描述 处理建议
Node {node_id} not found 节点不存在 检查节点 ID 是否正确
Task {task_id} not found 任务不存在 检查任务 ID 是否正确
Cannot cancel task in {status} status 无法取消已完成的任务 只能取消 PENDING 或 RUNNING 状态的任务
Task {task_id} is not completed 任务未完成 等待任务完成后再下载结果文件
Line file not found for task {task_id} 结果文件不存在 检查任务是否正确生成结果文件

8.4 支持的任务类型

任务类型 描述
ramgeo RAMGEO 计算任务

8.5 时间戳格式

所有时间戳均采用 ISO 8601 格式，例如：

  1. 2023-01-01T12:00:00Z

其中：

  • 2023-01-01: 日期（年-月-日）
  • T: 日期和时间的分隔符
  • 12:00:00: 时间（时:分:秒）
  • Z: UTC 时区标识符

8.6 文件大小限制

  • 单个文件最大大小: 100MB
  • 分片大小: 1MB
  • 支持分片上传大文件

8.7 并发限制

  • 最大并发连接数: 1000
  • 最大并发任务数: 100

8.8 性能指标

  • API 响应时间: < 100ms
  • 文件传输速度: > 10MB/s
  • 任务处理吞吐量: > 100 任务/分钟

9 Mallab 调用说明

  • 原始调用: 修改直接在Mallab中调用ramgeo.exe。
  • 通过API调用: 通过REST API上传任务文件，查询任务状态，下载结果文件。

9.1 定义函数

  1. % 主函数：通过API处理多个任务
  2. function processTasksWithAPI(NA, nam)
  3.     % API服务器地址
  4.     api_base_url = 'http://192.168.84.251:8080/api/v1';
  6.     % 遍历所有任务
  7.     parfor n = 1:NA
  8.         % 获取当前目录路径
  9.         current_dir = fullfile('.', 'TLtemp', ['tltemp' num2str(n, '%03d')]);
  11.         % 切换到当前任务目录
  12.         cd(current_dir);
  14.         try
  15.             % 1. 上传任务文件到API服务器
  16.             task_id = uploadTaskFile(api_base_url, current_dir);
  18.             if ~isempty(task_id)
  19.                 % 2. 轮询任务状态，直到完成
  20.                 task_completed = pollTaskStatus(api_base_url, task_id);
  22.                 if task_completed
  23.                     % 3. 下载结果文件
  24.                     downloadResultFiles(api_base_url, task_id, current_dir);
  25.                 else
  26.                     warning('任务 %s 未成功完成', task_id);
  27.                 end
  28.             else
  29.                 warning('任务 %d 上传失败', n);
  30.             end
  31.         catch ME
  32.             warning('处理任务 %d 时出错: %s', n, ME.message);
  33.         end
  35.         % 返回到原始目录
  36.         cd(nam);
  37.     end
  38. end
  40. % 函数1：上传任务文件
  41. function task_id = uploadTaskFile(api_base_url, current_dir)
  42.     task_id = '';
  44.     % 检查ramgeo.in文件是否存在
  45.     ramgeo_file = fullfile(current_dir, 'ramgeo.in');
  46.     if ~exist(ramgeo_file, 'file')
  47.         warning('文件不存在: %s', ramgeo_file);
  48.         return;
  49.     end
  51.     % 构建上传URL
  52.     upload_url = [api_base_url '/tasks/upload'];
  54.     % 准备HTTP请求选项
  55.     options = weboptions('RequestMethod', 'POST', ...
  56.                          'MediaType', 'multipart/form-data', ...
  57.                          'Timeout', 30, ...
  58.                          'ContentType', 'json');
  60.     try
  61.         % 上传文件
  62.         response = webwrite(upload_url, options, 'file', ramgeo_file);
  64.         % 提取任务ID
  65.         if isfield(response, 'task_id')
  66.             task_id = response.task_id;
  67.             fprintf('任务上传成功: %s\n', task_id);
  68.         end
  69.     catch ME
  70.         warning('上传文件失败: %s', ME.message);
  71.     end
  72. end
  74. % 函数2：轮询任务状态
  75. function task_completed = pollTaskStatus(api_base_url, task_id)
  76.     task_completed = false;
  77.     max_attempts = 360000; % 最多轮询100小时（5秒间隔）
  78.     poll_interval = 5; % 5秒
  80.     % 构建状态查询URL
  81.     status_url = [api_base_url '/tasks/' task_id];
  83.     for attempt = 1:max_attempts
  84.         try
  85.             % 获取任务状态
  86.             options = weboptions('Timeout', 10, 'ContentType', 'json');
  87.             response = webread(status_url, options);
  89.             % 检查状态字段
  90.             if isfield(response, 'status')
  91.                 status = upper(response.status);
  93.                 fprintf('任务 %s 状态: %s (尝试 %d)\n', task_id, status, attempt);
  95.                 % 检查任务是否完成
  96.                 if strcmp(status, 'COMPLETED')
  97.                     task_completed = true;
  98.                     fprintf('任务 %s 已完成\n', task_id);
  99.                     return;
  101.                 elseif strcmp(status, 'FAILED')
  102.                     error_msg = '未知错误';
  103.                     if isfield(response, 'error') && ~isempty(response.error)
  104.                         error_msg = response.error;
  105.                     end
  106.                     warning('任务 %s 失败: %s', task_id, error_msg);
  107.                     return;
  109.                 elseif strcmp(status, 'PENDING') || strcmp(status, 'SCHEDULED') || strcmp(status, 'RUNNING')
  110.                     % 任务仍在运行，继续等待
  111.                     pause(poll_interval);
  113.                 else
  114.                     warning('未知状态: %s', status);
  115.                     pause(poll_interval);
  116.                 end
  117.             else
  118.                 warning('响应中没有status字段');
  119.                 pause(poll_interval);
  120.             end            
  121.         catch ME
  122.             warning('获取任务状态失败: %s', ME.message);
  123.             pause(poll_interval);
  124.         end
  125.     end    
  126.     warning('任务 %s 轮询超时', task_id);
  127. end
  129. % 函数3：下载结果文件
  130. function downloadResultFiles(api_base_url, task_id, current_dir)
  131.     % 要下载的文件类型
  132.     file_types = {'.line', '.grid'};
  134.     for i = 1:length(file_types)
  135.         file_type = file_types{i};
  136.         filename = [task_id file_type];
  138.         % 构建下载URL
  139.         download_url = [api_base_url '/tasks/files/' filename];
  141.         % 本地保存路径
  142.         save_path = fullfile(current_dir, filename);        
  143.         try
  144.             % 下载文件
  145.             options = weboptions('Timeout', 60, 'ContentType', 'binary');
  146.             data = webread(download_url, options);
  148.             % 保存文件
  149.             fid = fopen(save_path, 'wb');
  150.             if fid ~= -1
  151.                 fwrite(fid, data);
  152.                 fclose(fid);
  153.                 fprintf('文件下载成功: %s\n', save_path);
  154.             else
  155.                 warning('无法创建文件: %s', save_path);
  156.             end            
  157.         catch ME
  158.             warning('下载文件 %s 失败: %s', filename, ME.message);
  159.         end
  160.     end
  161. end
  163. % 函数4：获取API服务器状态（可选，用于测试连接）
  164. function server_status = checkServerStatus(api_base_url)
  165.     server_status = false;
  166.     try
  167.         status_url = [api_base_url '/status'];
  168.         options = weboptions('Timeout', 5, 'ContentType', 'json');
  169.         response = webread(status_url, options);
  170.         if isfield(response, 'status') && strcmp(response.status, 'ok')
  171.             server_status = true;
  172.             fprintf('API服务器状态正常\n');
  173.         end
  174.     catch ME
  175.         warning('无法连接到API服务器: %s', ME.message);
  176.     end
  177. end

9.2 主要功能说明：

  1. processTasksWithAPI函数：

    • 主函数，替换原来的ramgeo.exe调用
    • 使用parfor并行处理多个任务

  2. uploadTaskFile函数：

    • 上传ramgeo.in文件到API服务器
    • 返回任务ID

  3. pollTaskStatus函数：

    • 每5秒查询任务状态
    • 支持任务状态：PENDING, SCHEDULED, RUNNING, COMPLETED, FAILED
    • 最多轮询1小时（可根据需要调整）

  4. downloadResultFiles函数：

    • 下载任务结果文件（.line和.grid）
    • 保存到当前目录

  5. checkServerStatus函数（可选）：

    • 测试API服务器连接状态
